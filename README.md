# Stage Gender

Stage Gender 是一个面向亚洲跨性别角色表演传统的静态数字档案网站原型。

## 页面

- 首页：昆曲、京剧、日本歌舞伎、越剧、孔剧五个剧种入口
- 昆曲：A–F 资料板块、人物对应图片、点击查看人物详情、作品视频外链
- 关于我们：来自 `ABOUT(1).docx` 的使命、范围、研究方法、团队与版权说明
- 入门指南：来自 `入门指南(1).docx` 的观览方法与资料入口
- 比较、表演体系：后续填充页面

## 部署

这是无构建步骤的 HTML/CSS/JS 静态站点，可直接部署到 GitHub Pages、Netlify 或任何静态托管服务。
